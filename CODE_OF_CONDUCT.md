# Code of Conduct

## Our Pledge

We are committed to keeping the **Strife** community welcoming, constructive, and focused on rigorous engineering. Participation in this project—whether in issues, pull requests, code reviews, or discussions—is harassment-free for everyone regardless of background or experience level.

## Expected Behavior

- **Focus on technical evidence:** Support claims about correctness, performance, or anomalies with reproducible seeds (`--seed`), `history.jsonl` / `.edn` traces, `schedule.json`, or measured benchmark commands.
- **Critique code and schedules, not people:** Keep code reviews direct, constructive, and respectful.
- **Respect maintainer and contributor time:** Keep issues and pull requests focused, minimal, and aligned with [`CONTRIBUTING.md`](CONTRIBUTING.md) and [`GOVERNANCE.md`](GOVERNANCE.md).

## Unacceptable Behavior

- Harassment, personal attacks, or derogatory language of any kind.
- Publishing private information (such as credentials, internal hostnames, or undisclosed security vulnerabilities) without permission.
- Disruptive spam, automated low-effort pull requests, or off-topic promotion.

## Enforcement

Maintainers may edit, close, or remove comments, issues, or pull requests that violate this Code of Conduct, and may temporarily or permanently block accounts for repeated or severe violations.

To report a concern, contact the maintainers via the channels listed in [`SUPPORT.md`](SUPPORT.md) or [`SECURITY.md`](SECURITY.md).

*Adapted from the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct.html).*
