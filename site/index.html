Fuel-metered WebAssembly plugins with bit-for-bit PRNG replay.

Strife embeds a pure-Go WebAssembly 1.0 stack machine (pkg/workload/wasm.go) and declarative compiler. Every client invokes next_op(process, step, rand_u64, keys, values) -> i64 fed from its forked xoshiro256** stream.

03 // KERNEL-LEVEL INJECTION & SOLVER PERFORMANCE

Millisecond fault injection & server-side root-cause probes.

Replacing a docker exec per command with cmd/strife-agent lands partitions, signals and netem changes ~25–50x sooner, measured by strife bench inject in CI, while capturing kernel telemetry from /proc/pressure and cgroup v2.

Injection latency, pause (50 transitions, 3-node etcd, GitHub runner)

strife-agent (persistent HTTP, direct syscalls) P50: 1.37ms · P95: 1.94ms
inside the agent (request received → kernel call returned) P50: 0.35ms · P95: 0.38ms
docker exec (Docker CLI + exec + shell) P50: 37.5ms · P95: 41.0ms

Partitions land in 1.1ms and heal in 1.0ms through the agent, as nf_tables rules sent over netlink (4.0ms and 7.4ms when it forked iptables). Full table, method and host: docs/BENCHMARKS.md.

strife-agent encodes nf_tables batches and RTM_NEWQDISC / RTM_DELQDISC netlink packets directly in Go, sends signals via syscall.Kill after scanning /proc, and writes directly to cgroup v2 cgroup.freeze and io.max.

04 // FORMAL CONSISTENCY MODELS & WIRE-PROTOCOL CLIENTS

Six specification models and five zero-dependency database clients.

Every database wire protocol and consistency solver is implemented in pure Go standard library code, enforcing strict separation between definite failures (fail) and indeterminate outcomes (info).

Subsystem Identifier Implementation & Verification Guarantees
Model kv · set · queue · counter · idgen Wing & Gong / Lowe linearizability graph search with bitset state memoization, P-compositionality per key, symmetry reduction, and $O(N \log N)$ minimal witness extraction. Cross-checked against brute-force reference on 3,000 random histories.
Model txn (Elle-style DSG) Direct Serialization Graph over multi-key read/write micro-ops (wr, ww, rw, so, ro edges) + Tarjan SCC shortest-cycle finder. Detects Adya G0, G1a, G1b, G1c, G2 (Write Skew), and G-realtime across 6 isolation levels.
Model append (Elle list-append) Version orders recovered from what each read returned; G0–G2, G-single, G-realtime, lost appends, incompatible orders, duplicates and internal inconsistency. In a brute-force cross-check: 0 of 150,030 valid histories flagged, 99.81% of 49,970 invalid ones caught.
Client etcd (v3) & redis / valkey (RESP2) Atomic compare-and-set via etcd v3 Txn compare and Redis Lua EVAL. Per-run namespace isolation prevents cross-run state leakage; broken sockets are immediately discarded and trigger Jepsen process-ID rotation.
Client postgres & mysql / tidb Pure-Go wire protocol clients with the databases' default authentication (PostgreSQL SCRAM-SHA-256, MySQL caching_sha2_password) and TLS, registers and list-append transactions at any isolation level. Validated in CI on PostgreSQL 17, MySQL 8.4 and TiDB 8.5, including the anomalies their weaker levels allow.
Client kafka (3.x and 4.x) ApiVersions, Metadata v4, Produce v3 with acks=all and Fetch v4 of RecordBatch v2 (CRC-32C). Each key is a single-partition topic checked as a list: lost or reordered acknowledged records fail the run, stale reads after leader changes are reported. Validated on Kafka 3.9.1 and 4.1.0.
